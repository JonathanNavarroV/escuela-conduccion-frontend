# Escuela de Conducción - Frontend 🚗📚

Este es el frontend de la plataforma para gestión de una escuela de condicción. Está desarrollado en Angular 18 y se conecta con un backend NestJS vía API REST.

---

## 👨‍💻 Tecnologías

- Angular 18 (Standalone)
- TypeScript
- Angular Material + Bootstrap
- RxJS
- FormBuilder y Reactive Forms
- Arquitectura modular (core, shared, pages, etc.)
- Diálogos reutilizables (confirmación, formularios)
- Interfaz adaptable y responsive

---

## ✅ Funcionalidades implementadas

- Autenticación con login
- Gestión de usuarios (crear, editar, eliminar)
- Roles de usuario (super administrador, administrador de sede)
- Asociación de usuarios a sedes
- Validaciones personalizadas (correo, contraseña)

---

## Instalación y uso

### 1. Clona el repositorio:

```bash
git clone https://github.com/JonathanNavarroV/escuela-conduccion-frontend.git
cd escuela-conduccion-frontend
```

### 2. Instala las dependencias:

```bash
npm install
```

### 3. Levanta el proyecto:

```bash
ng serve
```

### 4. Accede a la aplicación desde el navegador:

`http://localhost:4200`

> Nota: Asegúrate de tener configurado el backend correctamente para que las solicitudes de la API funcionen correctamente cuando estén implementadas.
